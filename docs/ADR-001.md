# ADR-001 — O domínio da LegalByte é centrado em Requests

## Context

Inicialmente o domínio estava sendo modelado em torno de Executions.
Após analisar o fluxo de negócio, percebemos que o usuário não pensa em
"execuções". Ele realiza solicitações para que a plataforma resolva um problema.

## Decision

A entidade central do domínio será `Request`.

Uma Request pode gerar uma ou mais Tasks, que podem utilizar uma ou mais
Automations para realizar o processamento.

## Consequences

- O domínio fica alinhado à linguagem do negócio.
- A implementação das automações permanece como detalhe interno.
- Uma Request pode ser atendida por uma ou várias Tasks.
- Novos mecanismos de processamento podem ser adicionados futuramente
  sem alterar o conceito central do domínio.
